# SchoolMate 0.1

Статическое веб-приложение с расписанием уроков. Работает без сервера и сохраняет данные в `localStorage` браузера.

## Локальный запуск

Можно открыть `index.html` напрямую в браузере. Для запуска через локальный сервер выполните в папке проекта:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub и загрузите в него все файлы проекта.
2. Откройте **Settings → Pages** в репозитории.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.
5. Через несколько минут GitHub покажет адрес опубликованного приложения.

Все пути к ресурсам относительные, поэтому приложение работает и в подпапке вида `username.github.io/schoolmate/`.

## Структура

- `index.html` — каркас приложения и навигация;
- `css/style.css` — адаптивный интерфейс;
- `js/app.js` — данные, хранилище, экраны и редактор.

Расписание хранится под ключом `schoolmate.schedule.v1`. Хранилище привязано к браузеру и адресу сайта: данные не синхронизируются между устройствами и могут исчезнуть после очистки данных сайта.
